# Crew 0.26.0

Four reader fixes asked for on 13 November 2026, including a safe preview for
HTML files. One small data migration (back up first); no protocol or managed
block change. Built on `pocketcontext-core` 0.2.1.

- **HTML files open in a sandboxed preview.** Clicking an HTML or SVG attachment
  (in a draft, in review files, on tasks and notes) opens it in the file viewer,
  in a frame that runs the page's own scripts and links but is cut off from Crew.
  The frame has only `sandbox="allow-scripts"`, and the server serves the file
  with its own CSP sandbox: an opaque origin, `default-src 'none'`,
  `connect-src 'none'`, `form-action 'none'` and `frame-ancestors 'self'`. The
  page cannot read Crew's storage or DOM, call Crew as the owner, navigate Crew,
  open windows, submit forms or load anything from the network (no web fonts or
  CDN files; self-contained prototypes work fully). The viewer has Desktop
  (1440 px) and Mobile (390 px) widths, Open in new tab (still sandboxed) and
  Download. The preview address is signed for one attachment and expires after 5
  minutes (`POST /api/crew/attachment-preview`, signed in). Everywhere else HTML
  and SVG stay downloads, as before. Core 0.2.1 lets the reader page frame
  same-origin previews (`frame-src 'self'`); it framed nothing before.
- **Review files are uniform tiles.** "Files submitted for review" shows each file
  once, as a same-size tile: a preview cropped from the top (images) or a file-type
  badge, the name on one line (full name on hover), type and size, and a corner
  download button. The tiles wrap, two per row on a phone. The viewer steps
  through all submitted files with previous / next and the arrow keys, across
  images and other files. Task and note files use the same tiles.
- **The session guide is a dialog.** The first "Copy prompt for a coding agent"
  click copies the prompt and opens a small dialog titled "Start a coding session
  as …": three steps and the whole prompt as a wrapped code block with a copy icon
  (no text area, no second Copy button), "Don't show this again" beside Got it.
  ×, Escape and Got it close it; focus stays inside and returns to the button. The
  ? is the same help icon as elsewhere and always reopens it. Nothing is added to
  the page, so agent cards keep their height.
- **"Don't show this again" holds across browsers.** It is a server setting
  (`crew_settings.session_guide_off`, `settings.update`), no longer this browser's
  storage. A browser that still has the old choice carries it over once.
- **Agent cards keep Start a session in their footer**, inside the card frame, so
  cards in a row have equal height.

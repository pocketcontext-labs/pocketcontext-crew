# Crew 0.25.0

Eight reader fixes asked for on 13 November 2026. No data migration, protocol,
managed block, skill or capabilities change.

- **Agent cards show briefs as text, not Markdown.** The card preview turns the
  brief into plain text, one line per heading, list item or paragraph, without
  `##`, `**`, backticks, link addresses or raw HTML. It stays clamped to whole
  lines. A brief without Markdown reads as before.
- **Every filter chip on a card filters.** Label chips already filtered the board.
  Now Ready and On hold filter by readiness, and Won't do filters by status. All of
  them share one hover, focus and keyboard behaviour and never open the card. The
  status filter, its address (`status=wont_do`) and the `status:` search token
  accept Won't do.
- **Sort is beside Filters.** The board's Sort is its own toolbar control showing
  the current order (Last updated or Oldest hold first). The Filters panel holds
  only readiness, label and status, and its count no longer includes the sort.
- **The Start a session toast shows when it will close.** It closes after 6
  seconds, with a thin bar that shrinks over that time and a 200 ms fade. Hover or
  focus pauses both. Dismiss is an × icon, and View is the only text button.
  Reduced motion skips the animation but keeps the timeout. A toast that needs
  action (manual copy, failure) stays.
- **The Archive page scales.** It now has tabs with counts (Tasks, Notes, Buckets,
  Inactive agents), title search, a label or bucket filter and sort by archived date
  or title, all kept in the address. Each row shows when and by whom the record was
  archived. Rows show 50 at a time with Show more. Notes hidden by an archived
  bucket appear as one group with Restore bucket. Restore selected restores several
  records and reports any that fail.
- **Start a session is clear for new users.** Home shows the agent as one (avatar,
  name, Agent tag, first line of the brief on hover). The button reads **Copy prompt
  for a coding agent**, and the toast says to paste it into a new session in your
  coding agent. The first click opens a short three-step guide with the copied prompt
  and its own Copy button, until "Don't show this again". The ? button opens it
  again. The copied prompt is unchanged.
- **Review images no longer flicker while you type.** Markdown image and link
  components were recreated on every render, so each keystroke in the decision
  note remounted the draft's images. They are now defined once for every Markdown
  view, and the decision note no longer re-renders the dialog.
- **One-click Download.** The image viewer has Download beside Open original.
  Image thumbnails in task and note files, and every file submitted for review,
  have a Download link. Files keep their original names, spaces and non-ASCII
  characters included, behind the same sign-in as viewing.

## Upgrade

Replace the binary or image and upgrade paired clients to 0.25.0; see
[Crew 0.24.1 to 0.25.0](../upgrades.md). From 0.23.1 or earlier, follow the
0.23.1 to 0.24.0 notes first.

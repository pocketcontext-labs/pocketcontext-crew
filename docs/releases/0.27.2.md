# Crew 0.27.2

Two reader fixes. No data migration, protocol, managed block, skill or
capabilities change.

- **The session instructions dialog no longer jumps.** Read, Edit and History
  each gave the dialog a different height, and Edit disappeared from the button
  row in Edit and History, so the buttons you had just clicked moved under the
  pointer. The dialog now keeps one size in every view (pinned near the top on a
  desktop, full screen on a phone), and Read, Edit and History are one segmented
  control that is always there, with the current view pressed. Only the area below
  the toolbar changes: long instructions scroll inside it, the Edit textarea fills
  it with Save and Cancel below, and short History sits at its top. An unsaved
  hand edit is kept while you look at Read or History, until Save or Cancel.
- **The file viewer keeps its controls in one place.** Images opened in a
  full-window dark viewer with arrows at the screen edges, while other files
  opened in a small light dialog with previous and next at its top right, so
  stepping from an image to a zip moved every control. Every file now opens in
  the same full-window viewer with one bar: the name, the zoom group, then one
  cluster of previous, `n / N`, next, Download, Open original and close. Controls
  that do not apply to a file (zoom and Open original for a zip or PDF) stay in
  place, disabled. The counter has a fixed width, long names are truncated with
  the full name on hover, the step button you used keeps focus in the next file,
  and Left/Right and Escape work on every file type. Files without a preview show
  a centred placeholder with name, size and Download.

## Upgrade

Replace the binary or image and upgrade paired clients to 0.27.2; see
[Crew 0.27.1 to 0.27.2](../upgrades.md). From 0.26.0 or earlier, follow the
0.26.0 to 0.27.0 notes first.

# Crew 0.9.0

The shared server moved to `pocketcontext-core`, and Crew now has its own identity
on your computer. No data format, database, backup or hosted container contract
changed.

## What changes for you

- **Own skill and registry.** The skill is `pocketcontext-crew` (directories such as
  `~/.claude/skills/pocketcontext-crew`), with its own markers and a registry at
  `<config>/pocketcontext-crew/profiles.json`. Earlier shared skills and the
  `<config>/pocketcontext/` registry are left untouched.
- **New default port for new projects: 8099.** Existing projects keep their saved
  port.
- **`--version` prints `pocketcontext-crew VERSION`.** Installers accept the earlier
  output when replacing an earlier release.
- **Instance check.** A 0.9 client recognizes a running earlier release so it can
  be diagnosed and stopped, but never adopts it. Upgrade the server and its paired
  clients together.

## New

`upgrade-check --db DB [--from VERSION] [--inventory]` is a read-only local
diagnostic. See the upgrade runbook in [upgrades](../upgrades.md).

Hosted operators need no action: delivery uses the same volume and image repository.
Public routes are unchanged, pinned by a golden table.

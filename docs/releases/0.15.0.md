# Crew 0.15.0

Terminology release. Crew drops the coined term "shared memory" for the plain nouns of its
data model: notes, buckets, tasks, agents and reviews. 0.14.0 renamed the reader pages
(Tasks and Notes); 0.15.0 finishes the change everywhere else. No data format, protocol
version, operation, field, route or managed instruction block changed. The capabilities
document's content is unchanged; `capabilities_digest` changes only through
`server_version`, as in every release.

## Skill

- The skill, router and remote skill descriptions now say "notes, tasks and human review",
  and the workflow, example and webhook references say notes instead of memory.
- The webhook reference now says the Owner comment wake and the bot handoff limit are set
  under Wake rules on the reader's Connect page (moved there in 0.14.0).
- Run `skill` on each computer with a Crew profile to install the updated files.

## MCP and CLI

- The MCP server instructions now say Crew "coordinates notes, tasks and human review".
- The `crew_write` tool description no longer claims it cannot record approval decisions,
  which has been wrong since 0.12.0: it now says a review decision is recorded only when
  the owner delegates it, and that webhook URL and secret entry stay in the owner's browser.
  `crew_read` and the CLI `write` help use the same wording.

## OAuth consent

- The consent and connected-apps text says apps "read and change notes and tasks in every
  bucket". The consent request no longer mentions "supporting knowledge and originals",
  inherited text for APIs Crew does not have. The OAuth resource name is now
  "PocketContext Crew notes and tasks".

## Reader

- "Related memory" is now "Related notes"; the Guide, Home and starter text say notes and
  buckets. New installs seed starter briefs that read "Read relevant notes before work";
  existing agent briefs are not changed.

## Docs

- README, install, MCP and webhook docs use the same terms.

## Upgrade

Replace the 0.14.0 binary or image with 0.15.0 following the
[upgrade procedure](../upgrades.md), upgrade paired clients with the server and run `skill`
on each computer with a Crew profile.

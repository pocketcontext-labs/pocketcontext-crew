# Crew 0.12.1

Reader polish. No data format, protocol version, skill, capabilities document, managed
instruction block or public route changed, so `capabilities_digest` is unchanged.

- **Search focus:** the header search, the AI Team board search and the Shared memory
  search show one focus ring around the whole box instead of a second ring around the
  field inside it.
- **Agent brief:** the Edit agent field opens at the full height of a long brief. It
  grows up to 70% of the window and then scrolls with a scrollbar. Before, it measured
  itself before the dialog opened and hid most of the text.
- **Agent cards:** the brief preview reflows to the card width and ends on a whole line
  with an ellipsis instead of cutting through a line. Hovering shows the full brief.
- **Approvals:** the whole card opens the review; the separate "Review exact draft"
  button is gone. Cards respond to Tab and Enter and are named after the task.

## Upgrade

Replace the 0.12.0 binary or image with 0.12.1 following the
[upgrade procedure](../upgrades.md), and upgrade paired clients with the server.

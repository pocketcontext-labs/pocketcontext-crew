# Crew 0.18.1

Reader fix. No data format, protocol version, skill, capabilities document, managed
instruction block or public route changed, so `capabilities_digest` is unchanged.

- **Session instructions:** on a manually started agent's card, **Show full
  instructions** now opens the instructions in a dialog of their own, with
  **Copy prompt**. Before, they expanded inside the narrow card and spilled behind
  the neighbouring agent cards, which stretched over the text and pushed the last
  card off the right edge. Long lines and code blocks scroll inside their own box,
  other cards keep their height and the Agents page never scrolls sideways.

## Upgrade

Replace the 0.18.0 binary or image with 0.18.1 following the
[upgrade procedure](../upgrades.md), and upgrade paired clients with the server.

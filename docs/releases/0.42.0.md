# Crew 0.42.0

Get started now walks you through assigning a Ready task, pasting the startup prompt into your agent chat, and reviewing the first draft. The starter task gives the agent something concrete to submit for approval.

**Copy startup prompt** includes the workspace’s MCP address so agents can verify the connection before reading or writing. All agents can use session templates for coding, research, drafting, dispatcher work and go-to-market tasks.

Owners can save a changed draft and request approval in one click. Agents submit work for review and the owner decides when the task is done. The mobile board, agent cards and action menus also have updated layouts.

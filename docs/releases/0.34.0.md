# Crew 0.34.0

A new Home, a create menu and a floating tab bar. No data migration, protocol,
managed block, skill or capabilities change.

- **Home is a sectioned page.** On every width, Home shows **Needs you**, **Agents**
  and **Recent** as consistent cards. Needs you has two tappable tiles with live
  counts: approvals waiting (opens Approvals) and tasks on hold (opens the board
  filtered to open tasks on hold), then the drafts waiting and any stuck task.
  Agents lists every active agent A–Z, none featured: initials, name and a short
  status from its open tasks ("1 in review", "2 in progress · 1 on hold", "No open
  tasks"). The row opens the agent; its ⋯ has Open agent and Show tasks, and for a
  manually started (coding) agent also **Copy prompt for a coding agent** and **How
  coding sessions work**. The loose Copy prompt box, its separate ? and the Agent tag
  are gone from Home, and so are the five status tiles (the board keeps its column
  counts and its over-3-days hold filter). Recent shows the latest tasks and notes
  with relative dates.
- **"Read how it works" is easy to tap.** The first-run line is now a full-width row
  at least 44 px tall that opens the Guide, with a 44 px ✕ that hides it in that
  browser. How it works stays in Home's page ⋯ on a phone.
- **+ on Home creates anything.** Home's + (the phone top bar, or **＋ New** on wider
  screens) opens a small menu anchored to it, with 44 px rows: Task, Note (once a
  bucket exists), Bucket, Agent and Shared page. Shared page asks for a title, creates
  a draft and opens it on Shared ready to write; publishing still happens only in the
  owner's browser. On Tasks and Notes, + still creates that page's item directly.
- **A floating tab bar.** On a phone the bottom tabs are a frosted, translucent pill
  inset from the screen edges with a soft shadow, and the page scrolls underneath.
  The current tab has a soft grey-green highlight behind its icon and label, and
  Approvals shows a small dot instead of a number while drafts wait (the count is
  still in its accessible name). The five tabs stay equal and never move. Desktop is
  unchanged.

## Upgrade

Replace the binary or image and upgrade paired clients to 0.34.0; see
[Crew 0.33.1 to 0.34.0](../upgrades.md). From 0.33.0 or earlier, follow the earlier
notes first.

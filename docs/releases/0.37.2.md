# Crew 0.37.2

One reader fix. No data migration, protocol, managed block, skill or
capabilities change.

- **Shared shows every status at once on a desktop.** Above 680 px, the Shared
  page shows Drafts, Live, Revoked and Archived as one row of chips with their
  counts, the same chips as the Tasks agent row, instead of the one-at-a-time
  switcher 0.37.1 used on every width. Clicking a chip selects that status and
  filters the list; only the selected chip is highlighted, and clicking it again
  keeps it. Phones keep the 0.37.1 switcher. The default (Live, or the first status
  that has shared pages), the `?show=` address and the focused shared page are
  unchanged. Chip hover styles, on Shared and on the Tasks agent row, now apply
  only on devices that hover, so a tapped chip never stays lit.

## Upgrade

Replace the binary or image and upgrade paired clients to 0.37.2; see
[Crew 0.37.1 to 0.37.2](../upgrades.md). From 0.36.0 or earlier, follow the
0.36.0 to 0.37.0 notes first.

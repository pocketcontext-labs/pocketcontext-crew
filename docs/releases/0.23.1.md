# Crew 0.23.1

A small reader fix. No data migration, protocol, managed block, skill or
capabilities change.

- **Rewrite with an agent** in the session instructions dialog could lose its
  "Rewrite prompt copied" confirmation when clicked right after the dialog opened:
  a reset meant for a new revision ran after the click. The copied state now
  belongs to the revision it was copied at, so it only clears when the
  instructions actually change. This was the real cause of the intermittent
  reader test failure that 0.23.0's longer test wait did not fix on macOS.

## Upgrade

Replace the binary or image and upgrade paired clients to 0.23.1; see
[Crew 0.23.0 to 0.23.1](../upgrades.md). From 0.22.0, follow the 0.22.0 to 0.23.0
notes first (one data migration, back up first).

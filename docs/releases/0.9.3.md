# Crew 0.9.3

Patch release so task writes accept an agent name for `assigned_agent`. No data format,
protocol, capabilities schema, default subscription or public route changed.

## Fix

`task.create`, `task.update` and `task.claim` looked up `assigned_agent` as a record ID
only, so an agent name returned 404 even though task reads and bucket assignment accept
names. These writes now accept an ID or unique exact name and store the agent ID.

An unknown or ambiguous name returns 400, as bucket assignment does. An unknown value
that used to return 404 now returns 400 "Agent not found". Archived agents are still
refused.

Wake behavior is unchanged. A task an agent creates for itself as Ready and `todo` is a
dispatch request and wakes the dispatcher; Ready and `in_progress` records it as
self-started; Waiting emits no wake.

## Upgrade

Replace the 0.9.2 binary or image with 0.9.3 following the
[upgrade procedure](../upgrades.md). Upgrade the server and its paired clients
together. Hosted operators need no action.

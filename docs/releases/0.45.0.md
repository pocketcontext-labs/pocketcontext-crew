# Crew 0.45.0

A worker can reply to a delegated task and mark it Done. The coordinator can
read the reply and status from the same task. Roles on the owner's connection
can edit and reassign internal tasks. Task history records the declared editor
separately from the assignment.

The owner can still review a saved draft before using it outside Crew. Closing
the internal task neither approves the draft nor publishes it.

See the [upgrade and rollback instructions](../upgrades.md).

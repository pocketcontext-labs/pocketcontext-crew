# Crew 0.39.1

Open a menu in Crew to find the Copy action by its icon and label. After
the copy succeeds, a check briefly takes the place of the icon. Inline Copy
buttons beside draft options and code blocks keep their compact appearance.

## Upgrade

Replace the binary or image and upgrade paired clients. The database format
matches 0.39.0. [Upgrade and rollback steps](../upgrades.md#crew-0390-to-0391)

# Crew 0.33.1

One phone reader change. No data migration, protocol, managed block, skill or
capabilities change.

- **Notes switch buckets like the Tasks board.** On a phone (680 px or less), the
  horizontal row of bucket chips, where later buckets sat off-screen, is replaced
  by the same sticky switcher as the Tasks board, directly under the top bar:
  `‹  All · 402  (1 of 10)  ›`. Previous and next never move and are greyed out in
  place on the first and last position; there is no swipe and, with this many
  positions, no dots, only "x of y". Tapping the name opens a list of every
  option, All first and then every bucket alphabetically, each with its live note
  count and a check on the current one; a long list scrolls inside the screen. The
  notes start right below the switcher, with title, bucket, relative date and a
  one-line snippet. While a bucket is selected, the page ⋯ has Edit bucket; the
  Filter and sort sheet keeps every bucket with its own ⋯. Desktop is unchanged.

## Upgrade

Replace the binary or image and upgrade paired clients to 0.33.1; see
[Crew 0.33.0 to 0.33.1](../upgrades.md). From 0.32.1 or earlier, follow the
0.32.1 to 0.33.0 notes first.

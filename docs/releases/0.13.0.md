# Crew 0.13.0

Reader improvements. No data format, protocol version, skill, capabilities document,
managed instruction block or public route changed, so `capabilities_digest` is unchanged.

## Shared memory

- Click a bucket card to show only its notes; click it again, or pick All buckets, to
  show every note. The selected card is outlined and the bucket menu follows it.
- Each bucket card has its own Edit button. Cards show the responsible agent and the
  number of notes instead of the description, which stays in the edit dialog and as a
  tooltip.
- The page's own search box is gone: the search in the header finds notes, tasks and
  agents.
- Sort buckets by name, number of notes or last activity, and notes by last updated,
  created, title or bucket.
- The bucket filter and both sorts are kept in the address (`#/memory?bucket=…&sort=…`),
  so a reload or a shared link keeps them.

## AI Team board

- The assignment menu can show one agent's tasks, with a count for each agent, next to
  All, Unassigned and Invalid assignments. Column counts follow the filter, and Show all
  tasks clears it.
- The filter is kept in the address (`#/team?agent=…`).

## Grok bot mappings

- Mapping cards show the bot's display name, or the agent name with a shortened bot
  reference when no name is saved, instead of placeholder text.
- Each mapping has an optional bot display name. It is sent as `bot_name` only when you
  change it. The MCP `crew_write` description and the webhook setup prompt now mention
  `bot_name`. As before, changing a mapping's name cancels pending wakes for that agent's
  Ready tasks.

## Upgrade

Replace the 0.12.x binary or image with 0.13.0 following the
[upgrade procedure](../upgrades.md), and upgrade paired clients with the server.

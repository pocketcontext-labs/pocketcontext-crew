# Crew 0.44.0

Ask a connected chat to work as a Crew agent or switch roles in the same conversation. The chat reads the selected agent’s saved instructions and brief. Existing claims stay with their original session. The reader shows who holds each task and groups an agent’s active claims by session.

Coordinators can delegate linked tasks to specialists and collect their recorded replies. Any role can preview instruction changes for multiple agents, apply confirmed edits and track acknowledgments separately. Parallel work uses the connected client’s worker capabilities or the configured dispatcher.

Back up the complete project before upgrading. Refresh MCP tool descriptions and any installed Crew skill. See the [upgrade and rollback instructions](../upgrades.md).

# Crew 0.39.0

Open a task’s **Draft for review** to edit each alternative by name, choose
whether the reviewer can pick one or several, and add the intended recipient.
Requesting approval freezes that version. Saving changes to the submitted
draft withdraws its pending review, and the original submission stays in the
task’s review history. Open a pending review from **More → Review the draft**.

Approvals show the full task title, recipient when supplied, and character
count and channel for each text option. The Copy button copies the reply text.
The author’s **Note for you** appears separately. Pick-one approvals name the
chosen option on the Approve button.

Task descriptions show the brief. Task write operations return a warning when
the description contains a copy or variant block. The original Markdown is
available in Edit. On a phone, tap the current tab again to return to the top of
the list. Copy buttons briefly show a check when copying succeeds.

## Upgrade

Back up before starting 0.39.0. Two migrations add working options to tasks
and selection and recipient to frozen reviews. Upgrade paired clients, run
`skill` once, and refresh MCP tool schemas. Crew uses PocketContext Core
0.3.0 with its single-account policy. Rollback requires the complete backup
and matching previous binary or image. [Upgrade and rollback steps](../upgrades.md#crew-0381-to-0390)

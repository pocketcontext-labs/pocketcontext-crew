# Crew 0.11.0

A simpler reader for first-time and everyday use. No data format, protocol version, skill,
capabilities document or public route changed, so `capabilities_digest` is unchanged.
The server moves to pocketcontext-core 0.1.4.

## Getting started

- **Home** is the new landing page: a Get started checklist (create the crew, connect an
  agent, give a first task, review a first draft) that ticks itself from workspace data,
  what needs you, task counts and recent updates. AI Team moves to `#/team`.
- **Help** buttons explain each page, section and non-obvious field, and a **Guide** at
  `#/guide` shows how Crew works, with a glossary.
- **Connect an agent** at `#/connect` gives the setup steps for the install: the MCP address
  and connected apps on a domain, or the command-line skill without one. Optional webhook
  setup is collapsed, shows one step at a time and reduces to a status line once set up.

## Everyday use

- Every page has a bookmarkable address, and Back, reload and page titles follow it.
- **Global search** from every page (`/` or Cmd/Ctrl+K) finds tasks, notes, agents and
  buckets, with a bookmarkable results page.
- Notes and task Markdown fields open on **Read**, with **Edit** second; Save stays visible
  in Edit, and Reason for change appears only after an edit.
- Dialogs keep one height across views, close from the backdrop, ask before discarding
  unsaved edits and become full-height sheets on phones. The phone menu is a two-row grid,
  form fields no longer make iOS zoom, and data refreshes silently.
- Sign-in is one action per screen.

## Agent setup

The OAuth consent page now uses Crew's design. A signed-out owner can log in and return to the
request; only `/oauth/authorize` targets are accepted. `/oauth/connections` opens the Connect
page. Grok setup recommends authorizing every bot once in a group chat with the owner, with
each bot's own chat as the fallback.

## Upgrade

Replace the 0.10.0 binary or image with 0.11.0 following the
[upgrade procedure](../upgrades.md), and upgrade paired clients with the server. No skill or
webhook routine update is needed.

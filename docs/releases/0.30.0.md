# Crew 0.30.0

Sign in from the home-screen app with a code, a real Crew icon, and one floating
dialog header.
Built on `pocketcontext-core` 0.2.2. No data migration, protocol, managed block,
skill or capabilities change.

## Sign-in code for the home-screen app

- **A six-digit code in the sign-in email.** An installed home-screen web app does
  not share cookies or storage with the browser, and email links always open the
  browser, so the link could never sign the app in. The email now leads with a
  code: the subject reads "123456 is your PocketContext sign-in code", and the body
  shows the code alone (Gmail offers Copy code; iOS suggests it above the
  keyboard), then the expiry, a warning to enter it only on your Crew domain, the
  browser link and a footer. A plain-text part says the same.
- **Check your inbox takes the code.** The screen has a one-time-code field
  (numeric keypad, paste with spaces or dashes, signs in at six digits). In the
  home-screen app it says to enter the code because the link opens the browser.
  After sign-in you land where you were going.
- **Safe by design.** The code belongs to the login request of the app that asked
  for it, works for 15 minutes and once, and shares a lock with the link: either
  one signs in, never both. Wrong codes count down ("That code is wrong. 4 tries
  left."); the fifth ends the request, link included. Redemption is rate-limited
  globally and per address. The link still asks to confirm Log in, so mail
  scanners cannot spend it.
- **Sessions last 30 days and roll.** Hosted sign-ins last 30 days, and the reader
  renews the session when it opens and when you come back to it.

## Crew icon on the home screen

- **The Crew mark everywhere.** Add to Home Screen used to show a grey letter
  placeholder. The reader now ships the chosen mark (one lime person, three agent
  dots on ink) as the apple-touch-icon, web app manifest icons (192, 512 and a
  maskable 512) and the tab favicon, with the label "Crew". All sizes are
  generated from one master by `ui/scripts/icons.mjs`, and every link carries a
  content-hash `?v=` so browsers pick up new art.
- **Opens as an app.** The manifest asks for a standalone window, so the
  home-screen Crew opens without the browser bar (iOS 16.4 and later). On iPhone
  it keeps its own storage: sign in once inside it, with the code.
- Remove the home-screen icon and add it again to get the new art.

## One floating dialog header

- **One row at 320 px and up.** The header of the note, task, review, bucket,
  agent and session instructions dialogs no longer wraps the close button onto a
  second line. In the iOS Mail style, it shows round back and forward buttons on
  the left (always both, disabled when there is nowhere to go), the title (it
  ellipsizes and never wraps), one rounded pill of icon buttons ending in More,
  and a round close button on the right. The bar is translucent and content
  scrolls under it.
- **Icons with names.** Copy link is a link icon (it turns into a check with a
  brief "Copied"), Share as artifact a share icon, Copy prompt a copy icon. Every
  icon has an accessible name and a tooltip. Controls that do not apply stay in
  place, disabled (Share as artifact on a task, Copy link on a new record), so
  nothing moves between records or views.
- **More menu.** More opens a floating rounded card under the button with icon
  and label rows of at least 44 px: Copy link and Share as artifact, a note's
  History, then Archive (Deactivate for an agent) in red in its own last group.
  It closes on selection, a tap outside and Escape (which leaves the dialog open),
  moves with the arrow keys, Home and End, uses menu roles and scrolls when it is
  taller than the screen.
- The file viewer keeps its fixed cluster; its header row is checked to stay one
  row at 320 px too.

## Upgrade

Path-filtering proxies in front of a hosted install must pass
`POST /api/collections/users/auth-with-otp-code` and `GET` for `/apple-touch-icon.png`,
`/icon-192.png`, `/icon-512.png`, `/icon-maskable-512.png`, `/favicon.ico` and
`/manifest.webmanifest`. Replace the binary or image and
upgrade paired clients to 0.30.0; see
[Crew 0.29.0 to 0.30.0](../upgrades.md). From 0.28.0 or earlier, follow the earlier
notes first.

# Crew 0.38.1

Draft blocks show their full text in reviews, tasks, notes and comments. On a
phone the blocks stack. On desktop two channel variants can sit side by side.
Each block has its own Copy button beside the character count. In a review
option you can still leave feedback on a single variant or copy all variants
from the option menu.

Agent guidance now covers screenshots and files received in chat. An agent
with the original bytes can attach the file to the relevant task or note. When
only a preview is available, the agent asks the owner for the original through
the reader or an upload link.

## Upgrade

Upgrade paired clients, run `skill` once and refresh MCP tool descriptions.
See the [upgrade and rollback steps](../upgrades.md#crew-0380-to-0381).

# Crew 0.36.0

The reader speaks English, Deutsch and Italiano, gets a Settings page, and an agent
row on Home runs the action you choose. One data migration (back up first); no
protocol or managed block change.

- **Three languages.** Every reader screen (Home, Tasks, Notes, Approvals, Shared,
  Agents, Archive, Search, Connect, Guide and help, every dialog, the file viewer,
  sign-in and the upload page) is available in English, German and Italian.
  Choosing a language switches at once, without a reload, sets the page's `lang`
  and is saved on the server, so it follows you to other browsers. On first visit
  the reader follows the browser's language (German or Italian, otherwise English).
  Relative dates and durations follow the language ("vor 5 Min.", "5 min fa").
  What you and your agents write — titles, notes, comments, labels, agent names —
  is never translated. Strings live in catalogs per language
  (`ui/src/i18n/locales/<language>/`), English is the key and the fallback, and a
  test fails when a reader string is missing from a catalog.
- **Settings.** A new Settings page, opened from More on a phone or the sidebar on
  a wider screen, has Language; **Tapping an agent**; Account (the signed-in user
  and Sign out); and About (server version and build). Sign out and the server
  version left the page footer, and the phone More sheet no longer has Sign out.
- **Tapping an agent.** Tapping anywhere on an agent row on Home (except ⋯) runs
  that agent's default action: its own choice, otherwise the All agents choice,
  otherwise **Open agent**. All agents offers Open agent or Show tasks; each agent
  offers only what its ⋯ menu has, plus **Copy prompt for coding agent** for coding
  agents. Picking the All agents value on an agent follows All agents again, and a
  choice an agent no longer offers falls back the same way. ⋯ still opens the full
  menu.
- **Coding agents stand out.** Coding (manually started) agents on Home carry a
  small **Coding agent** tag, and their ⋯ menu has one **Copy prompt for coding
  agent** item (same copy and toast as before).
- **For agents.** `settings.update` also accepts `language` (`""`, `en`, `de`,
  `it`) and `agent_tap` (`{all, agents}`), any one of its three fields per call.

## Upgrade

Back up first, then replace the binary or image, upgrade paired clients to 0.36.0
and refresh MCP tool schemas; see [Crew 0.35.0 to 0.36.0](../upgrades.md). Older
binaries refuse the migrated database; rollback restores the backup. From 0.34.0 or
earlier, follow the earlier notes first.

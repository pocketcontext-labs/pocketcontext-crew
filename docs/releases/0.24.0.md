# Crew 0.24.0

Seven reader and API fixes asked for on 12 November 2026. No data migration,
protocol or managed block change. Run `skill` once and refresh MCP tool schemas
(the `links` descriptions changed, so `capabilities_digest` changes too).

- **Tasks link to tasks.** `links` on tasks and notes accepts task or note IDs.
  Before, every ID was looked up as a note, so a task ID failed with a bare 404.
  An unknown or malformed ID is now a 400 naming it (`unknown_link`), and a record
  can't link to itself (`self_link`). The reader's **Related** panel searches tasks
  and notes, shows each by title with its permanent link, and lists the records
  that link here under **Linked from**, so a relationship shows on both sides.
- **Comments tab.** The task dialog has Edit, **Comments** (with a count), Activity
  and Reviews. Comments lists only comments, with author, time, Markdown and inline
  screenshots, and holds the Add a comment box. Activity keeps the full history
  with plain labels (Comment, Updated, Review requested and so on) instead of action
  names like `task.comment`. `#/tasks/<slug>-<id>?tab=comments` (or `activity`,
  `reviews`) opens a task on that tab, and the address follows the tab.
- **Markdown briefs.** Agent brief and bucket Purpose use the same Read/Edit
  Markdown field as a task description. A filled-in field opens in Read. Saving and
  the 20,000-character limit are unchanged.
- **One-click Start a session.** The reader reads the session when the button
  renders, so one click copies the prompt, including on a phone. A toast confirms
  "Copied the session prompt for <name>." with View (opens Session instructions)
  and Dismiss. When the copy fails, the toast shows the prompt to copy by hand.
  Nothing stays on the card, and the wording no longer names particular tools.
  Copy link buttons now use the same copy helper, with the same fallback.
- **Start a session on Home.** Home has one compact `Start a session · <name>`
  button per active manually started agent. Bots, people and inactive agents never
  appear there, and there are no counts.
- **Image zoom.** The image viewer zooms in and out, resets, and has Fit width and
  100%. Pan by scrolling or dragging. Pinch and Ctrl/Cmd + wheel zoom, and so does
  a double-click or double-tap. The keys are `+`/`-`/`0`. Open original opens the
  image in a new tab. Changing image resets the zoom, swipes change image only when
  the image is fitted, and clicking the image never closes the viewer.
- **Floating label suggestions.** The Labels suggestions float over the form
  instead of pushing Hold down. Escape closes them without closing the dialog.

## Upgrade

Replace the binary or image and upgrade paired clients to 0.24.0, then run `skill`
on each computer with a Crew profile and refresh MCP tool schemas; see
[Crew 0.23.1 to 0.24.0](../upgrades.md). Rollback to 0.23.1 needs no restore, but
0.23.1 refuses to save a record that links to a task (a 404) until those links are
removed.

# Inherited PocketContext release notes

These notes (PocketContext 0.8.0 through 0.24.0) were inherited with the
PocketContext source Crew is derived from. They describe that upstream
infrastructure (tunnel, profiles, HTTPS, MCP, service and upgrade machinery) at
the time of each PocketContext release, not Crew releases, and are kept unchanged
for reference; their relative links follow the upstream repository layout. Crew's
own release notes are in the [parent folder](..), and Crew does not ship
PocketContext's knowledge features, spaces or reader chat.

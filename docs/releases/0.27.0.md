# Crew 0.27.0

Eight reader fixes asked for on 13 November 2026. No data migration, protocol,
managed block, skill or capabilities change.

- **Pick an agent on the board in one click.** A row of compact chips sits under
  the Tasks toolbar: All, then each active agent with its avatar and open-task count
  (Done and Won't do excluded), then Unassigned when some open tasks have no agent.
  The selected chip is highlighted; clicking it again, or All, shows every task.
  Archived agents are left out, and on narrow screens the row scrolls sideways.
- **The agent on a card filters too.** The avatar and name in a card's footer is
  one chip-style button, "Filter by agent <name>", that sets the same assignment
  filter as the agent row and the assignment select, without opening the card.
  Unassigned and inactive-agent cards stay plain. All three stay in sync and in the
  address (`?agent=`).
- **Filter chips no longer underline on hover.** Label, Ready, On hold and Won't
  do chips tint and darken their border on hover instead, with the pointer cursor
  and the focus ring.
- **One Related section on tasks and notes.** A note's Read view now has the same
  Related section as the task form: the ? help, TASK and NOTE tags, Remove, Linked
  from and "Link a task or note". Changing only links on a note's Read view shows
  Save note right there. Remove is a small × button, and an empty section says
  "No related items" above the search. Archived records stay read-only with the
  controls hidden.
- **Status explains Needs review.** The Status field has the standard ? with one
  line per status, and says why Needs review can't be picked: Crew sets it only when
  you or an agent requests approval for the saved draft (a status update to
  needs_review is refused), and a decision, a withdrawal or a draft edit moves the
  task back to In progress. A hint under the field says so on focus, and says a draft
  is waiting in Approvals while a review is pending.
- **Request approval is a real button.** The brown "Add a draft to request
  approval" text is now a secondary **Request approval** button (it replaces "Send
  draft for approval"), disabled with a grey "Save a draft first." until a draft is
  saved. The standard ? sits beside it on the same row, Review alternatives follow
  below, and the row has its own spacing before Related. The ? no longer gets a grey
  square behind it on hover anywhere.
- **The viewer toolbar is grouped.** Zoom (− level +), fit (Fit, Fit width,
  Actual size) and actions (Open original, Download) are three groups, with the
  actions on the right. Open original looks exactly like Download, with a ↗ icon,
  and still opens in a new tab. The fit button formerly labelled "100%" is now
  "Actual size", so only the zoom level reads as a percentage.
- **Copy coding prompt fits its card.** On agent cards the button reads "⧉ Copy
  coding prompt" at the normal button size, with its ? on the same centred row and
  even footer padding. After a copy it shows "✓ Copied" for 2 seconds. Home keeps
  "Copy prompt for a coding agent". The first click still copies and opens the guide.

## Upgrade

Replace the binary or image and upgrade paired clients to 0.27.0; see
[Crew 0.26.0 to 0.27.0](../upgrades.md). From 0.25.0 or earlier, follow the
0.25.0 to 0.26.0 notes first (one data migration).

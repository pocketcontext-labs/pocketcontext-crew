# Crew 0.40.0

Choose **Archive task** in a pending approval’s More menu to archive its task
and withdraw the review. Crew moves to the next approval when one is available.
Choose **Undo** in the toast to reopen the same task and review.

The reader, CLI and MCP share the revision-checked `review.restore` operation.
It checks the task and review before restoring them together.

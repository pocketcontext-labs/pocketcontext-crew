# Crew 0.11.1

Reader polish. No data format, protocol version, skill, capabilities document or public
route changed, so `capabilities_digest` is unchanged.

- **Approvals:** review buttons line up at the bottom of each card, previews show plain text
  ending on a whole line, and the redundant Human tag is gone.
- **Focus:** every text field, text area and dropdown shows the same focus style as the
  search box, including the login screen and the Write and Edit boxes.

## Upgrade

Replace the 0.11.0 binary or image with 0.11.1 following the
[upgrade procedure](../upgrades.md), and upgrade paired clients with the server.

# Crew 0.43.0

In Settings → Appearance, enable **Show instance line** and choose a color. A 3 px line stays at the top of the signed-in reader while you scroll or change pages. Each instance remembers its color when you hide the line. Other devices pick up the setting when you open or reload Crew. The line starts hidden, with amber selected.

On narrow screens, agent summaries wrap to fit the available width. Public development readers use manual refresh so a live-reload reconnect after switching mobile apps can no longer reload the page. Local development keeps live reload.

Back up the complete project before upgrading. The migration adds the two appearance settings. See the [upgrade and rollback instructions](../upgrades.md).

# Crew 0.27.1

One reader fix. No data migration, protocol, managed block, skill or
capabilities change.

- **Every agent is visible on a phone.** The Tasks board's agent row (All, each
  active agent with its open-task count, Unassigned) was one line that scrolled
  sideways, so on a phone most agents sat off the right edge behind a thin scroll
  bar. The row now wraps onto as many lines as it needs, with tighter chips under
  420 px and tap targets at least 32 px tall. Order (All first) and the selected
  chip are unchanged; on a desktop the row looks the same or simply wraps.

## Upgrade

Replace the binary or image and upgrade paired clients to 0.27.1; see
[Crew 0.27.0 to 0.27.1](../upgrades.md). From 0.26.0 or earlier, follow the
0.26.0 to 0.27.0 notes first.

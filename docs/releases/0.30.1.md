# Crew 0.30.1

One reader fix. No data migration, protocol, managed block, skill or capabilities
change.

- **Back returns from a Related task or note.** Clicking a row under Related (or
  Linked from) replaced the dialog with that record but started a new history
  trail, so the dialog's Back arrow was disabled and you could not return to the
  task or note you came from. Related rows now use the same link handling as
  record links in text (since 0.29.0): each click adds a step to the trail, the
  dialog's Back and Forward and the browser's Back and Forward walk it, and closing
  returns to the page underneath. Rows are real links, so Cmd/Ctrl-click,
  Shift-click and middle-click open the record in a new tab and Copy link works.
  Leaving a record with unsaved changes through a Related row asks first; declining
  keeps you on the record with your edits.

## Upgrade

Replace the binary or image and upgrade paired clients to 0.30.1; see
[Crew 0.30.0 to 0.30.1](../upgrades.md). From 0.29.0 or earlier, follow the
0.29.0 to 0.30.0 notes first.

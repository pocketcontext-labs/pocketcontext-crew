# Crew 0.2.0

Crew now exposes only its memory, task and review model. MCP has two tools,
crew_read and crew_write; spaces and inherited knowledge APIs/CLI commands are
removed. Old clients using those operations must switch to Crew operations.

Buckets can be assigned/reassigned through MCP with bucket.assign or bucket.update.
IDs or unique exact names resolve agents, and explicit null/empty clears assignment.
Reads retain responsible_agent IDs and add details and responsibility filtering.
Assignment events retain old/new IDs and attribution. Shared writes and owner-only
review decisions, bucket archival and agent deactivation are unchanged.

Upgrade preserves all Crew data and verifies a private legacy knowledge archive
before removing inherited collections. Keep the complete stopped pre-upgrade
backup and its matching release for rollback. See [upgrades](../upgrades.md).

A private database anchor binds the required archive and manifest hash. After
conversion, startup and backups reject a missing archive, changed manifest or
corrupt file. Archive publication flushes files and directory metadata before
schema retirement; interrupted preparation is cleaned under the writer lock.

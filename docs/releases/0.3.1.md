# Crew 0.3.1

The signed-in Crew interface now shows the running server version and source
revision. This information comes from the authenticated server, so it identifies
what is actually running rather than the browser bundle's version. Refresh the
workspace to recheck after an upgrade. If the server cannot supply version
information, the interface says it is unavailable.

Container builds now record the release version and source commit separately,
matching native release metadata. The version endpoint exposes only those two
fields, requires authentication and disables caching.

This patch includes all [0.3.0 webhook functionality](0.3.0.md), with no further
webhook schema or policy changes. It also removes an unnecessary request body from
retired-route tests that could cause an intermittent Windows connection reset.
Keep the existing complete-backup and stop-first upgrade procedure.

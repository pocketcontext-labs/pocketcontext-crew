# Crew 0.41.0

Use **Start in a chat** to continue a Crew agent in a new chat. Manual sessions and webhook executions share exclusive task ownership. Each agent starts with a short workflow you can edit or restore from revision history. Coding agents can use the optional coding template.

Enable automatic startup per agent after connecting an integration. Grok setup now walks you through the first chat for each bot, including the dispatcher. Each new work wake reads the agent’s current brief and saved instructions.

Shared supports creating additional drafts and previewing Markdown while editing. Tasks, Notes, Approvals and Shared have consistent empty states, and starter crew setup is available when all agents are inactive.

**Before upgrading**, finish or pause active webhook work and take a complete backup including the private webhook key. The upgrade pauses delivery. Sync the dispatcher and run a fresh test before enabling delivery again.
